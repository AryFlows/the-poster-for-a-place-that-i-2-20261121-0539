VELMARA — the island where the sea climbs the stairs. Stepped basalt
terraces rise out of a turquoise lagoon into a coral-gold sunset, and
one lone white watchtower keeps the light on the highest step. Come
for the long light; stay for the climb.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.png` (1024x1024, pure-stdlib Python — no PIL,
no network, no downloaded assets). The poster is painted entirely in
code: sky gradient, low sun, sea, stepped terraces and the watchtower,
with the place name set in a hand-built stroke font.
